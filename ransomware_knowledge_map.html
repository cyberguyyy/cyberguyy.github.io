🦠 What Is Ransomware?
Core concepts every SOC analyst must know before touching any alert.
🔴 Core DefinitionRansomware is malware that encrypts or exfiltrates victim data and demands payment (typically cryptocurrency) for restoration. Modern ransomware operators run professional criminal enterprises with support desks, negotiation teams, and affiliate programs.

🔐 Encryption Engine

Modern ransomware uses hybrid encryption — AES-256 for file encryption (fast), RSA-2048/4096 to encrypt the AES key (secure). The victim can't decrypt without the attacker's RSA private key.

Core Mechanism

💰 Extortion Model

Payment demanded in Monero or Bitcoin via Tor-hosted portals. Modern attacks use "double extortion" — encrypt AND steal data, threatening to publish on leak sites.

Business Model

🏭 RaaS Model

Ransomware-as-a-Service: Developers lease the ransomware kit to affiliates (hackers) who do the intrusion. Revenue is split ~70/30 or 80/20. LockBit, BlackCat, REvil all used this model.

Criminal Ecosystem

📤 Double Extortion

Attackers exfiltrate sensitive data BEFORE encryption. If ransom isn't paid, data is published on "shame blogs" or dark web leak sites — used against healthcare, legal, and finance firms.

Tactic

🌐 Triple Extortion

Adds DDoS attacks on the victim's infrastructure OR direct threats to victim's customers/partners. Pushes pressure beyond just encryption.

Advanced Tactic

⏱️ Dwell Time

Average attacker dwell time before detonation: 5–21 days. They map the network, escalate privileges, exfiltrate data, kill backups — THEN drop the payload. The encryption is the last step.

Key Insight
💡 SOC Key InsightBy the time you see file encryption, the attacker has likely been inside for days or weeks. Your job during detection is to identify the early-stage activity (credential theft, lateral movement) — not just the encryption event.

📊 By the Numbers (2023–2024)

  • Average downtime after attack: 21–24 days

🔄 Ransomware Attack Lifecycle
The full kill chain — from initial access to ransom note. Each phase maps to MITRE ATT&CK.
Phase 1 · Initial Access
Getting a Foothold
Attacker gains first entry via phishing email, exposed RDP, VPN vulnerabilities, or software exploits. This is your earliest detection opportunity.
T1566 Phishing T1133 External Remote Services T1190 Exploit Public App T1078 Valid Accounts
Phase 2 · Execution
Running Malicious Code
Payload executes via macros, PowerShell, or living-off-the-land (LOL) binaries like certutil, mshta, regsvr32. Often runs in memory to evade AV.
T1059 Command Scripting T1203 Exploitation for Exec T1218 Signed Binary Proxy
Phase 3 · Persistence
Staying Alive
Creates scheduled tasks, registry Run keys, new admin accounts, or installs backdoors (Cobalt Strike beacon, Metasploit). Ensures they can return if detected.
T1053 Scheduled Task T1547 Registry Run Keys T1136 Create Account
Phase 4 · Privilege Escalation
Becoming Admin / Domain Admin
Attackers need Domain Admin to push ransomware via GPO or PSExec. Techniques: Kerberoasting, Pass-the-Hash, DCSync, exploiting unpatched local privesc vulns.
T1558 Kerberoasting T1003 OS Credential Dumping T1548 Abuse Elevation Control
Phase 5 · Defense Evasion
Blinding the SOC
Disabling AV/EDR, clearing event logs, deleting Shadow Copies, disabling Windows Defender. This phase is highly detectable if your logging is configured properly.
T1562 Impair Defenses T1070 Indicator Removal T1490 Inhibit Recovery
Phase 6 · Discovery & Lateral Movement
Mapping & Spreading
Network scanning (nmap, ADRecon), discovering file shares, domain controllers, backup systems. Then moves laterally using PSExec, WMI, RDP, or compromised credentials.
T1018 Remote System Discovery T1021 Remote Services T1482 Domain Trust Discovery
Phase 7 · Exfiltration
Stealing Data (Double Extortion)
Data staged locally, then exfiltrated via Rclone, MEGAsync, FTP, or cloud sync tools to attacker-controlled storage. Look for large outbound transfers and unusual cloud tool installs.
T1048 Exfil Over Alt Protocol T1567 Exfil to Cloud Storage T1560 Archive Data
Phase 8 · Impact (Encryption)
Detonation
Ransomware deployed via GPO, PSExec, or WMIC across all endpoints simultaneously. Files encrypted, Shadow Copies deleted, ransom note dropped. This is when most orgs detect the incident.
T1486 Data Encrypted for Impact T1489 Service Stop T1491 Defacement
⚠️ Critical SOC TakeawayPhases 1–7 are where you WIN. If you catch unusual PowerShell, lateral movement, or large data transfers, you can stop the attack before encryption. By Phase 8, containment is reactive — the damage is done.
📦 Ransomware Types & Notable Families
Understanding the taxonomy helps you contextualize threat intel and map TTPs.

🗂️ By Type

  • Crypto Ransomware — Encrypts files. Most common. (WannaCry, LockBit)
  • Locker Ransomware — Locks the OS/screen, not files. (Reveton)
  • Wiper (Pseudo-Ransomware) — Destroys data, no real decryption. (NotPetya, Shamoon)
  • Doxware/Extortionware — Threatens to publish data (no encryption needed)
  • Mobile Ransomware — Android-targeting variants (ScaredyCat, Simplocker)
  • MBR Ransomware — Overwrites Master Boot Record (Petya original)

🏷️ By Delivery

  • Human-Operated (Big Game Hunting) — Manual intrusion, targeted. Highest damage.
  • Commodity/Automated — Mass spray campaigns via spam. Lower skill.
  • Supply Chain — Compromises software vendor to hit downstream (Kaseya/REvil)
  • Worm-Propagated — Self-spreads like WannaCry via EternalBlue
🔴 LockBit 3.0
Critical▼
Status: Disrupted (2024 Operation Cronos), successors active.
Notable: Most prolific RaaS ever. Used bug bounty to improve malware. 1,000+ victims.
TTPs: Exploits Fortinet/Citrix vulns, AnyDesk for persistence, Cobalt Strike C2. Encrypts in chunks for speed.
Extension: Random 9-char hex appended to files.
C2: Tor-based negotiation portal with countdown timer.
  • Targets ESXi/VMware for VM encryption
  • Exfiltrates via Stealbit custom tool
  • Kills 100+ services and processes pre-encryption
🟠 BlackCat (ALPHV)
Critical▼
Status: Disrupted by FBI (Dec 2023), splinters active.
Notable: Written in Rust — cross-platform (Windows, Linux, ESXi). Highly configurable JSON config.
TTPs: Compromised creds via IABs, uses Cobalt Strike/Brute Ratel, living-off-the-land heavily.
Extension: Configurable, often random.
  • First major Rust-based ransomware
  • Attacked MGM, Change Healthcare
  • Supports NTFS journal wipe for anti-forensics
🟡 Cl0p
Critical▼
Status: Active — pivoted to mass exploitation of file transfer software.
Notable: Exploited MOVEit, GoAnywhere, Accellion — zero-day focused approach. May skip encryption, rely solely on data theft.
TTPs: Mass exploitation of managed file transfer tools; automated exfiltration; multiple victim approach simultaneously.
  • Exfiltration-first model — no encryption needed
  • Shell company victims listed on blog simultaneously
  • Government agencies, airlines, banks affected
🔵 WannaCry
Historical▼
Status: Legacy (2017) but still triggers alerts — unpatched systems still vulnerable.
Notable: Used NSA's EternalBlue exploit (MS17-010 / SMBv1). Hit NHS, FedEx, 200,000+ systems globally in 72 hours.
Extension: .WCRY or .WNCRY
Kill Switch: Had accidental kill switch domain — sinkholed by security researcher.
  • Attributed to North Korea (Lazarus Group)
  • Port 445 SMB scanning behavior is detectable
  • Systems unpatched after 7 years still exist in networks
⚫ Conti
Defunct▼
Status: Dissolved 2022 after internal chat leaks. Members joined BlackBasta, Royal, etc.
Notable: Huge organized crime structure. Leaked playbooks are still used for training.
Legacy: Conti playbooks remain the gold standard for understanding ransomware TTP methodology.
  • Had 60+ active members at peak
  • Attacked Irish HSE healthcare system
  • Conti leaks revealed full internal ops structure
🟢 Black Basta
Active▼
Status: Active — believed to be Conti successors.
Notable: Sophisticated, targeted, $100M+ in ransoms. Initial access via Qakbot malware.
TTPs: Uses BazarLoader, Qakbot, Cobalt Strike; double extortion; ESXi targeting.
  • Doesn't maintain leak site — negotiates quietly
  • Fast encryption (full disk in hours)
  • Targets critical infrastructure

🔎 Key SIEM Queries to Build

  • Multiple file renames in short time span
  • Shadow copy deletion commands
  • wevtutil.exe clearing logs
  • Rclone.exe / MEGAsync process creation
  • Encoded PowerShell (-enc / -EncodedCommand)
  • PSExec usage outside IT admin accounts
  • New admin user creation after-hours
  • Outbound traffic to Tor exit nodes
  • BCDEdit modifying boot options
  • Ntdsutil.exe execution (AD database dump)

  • VirusTotal / Any.run — sandbox analysis
  • MITRE ATT&CK — TTP mapping for each group
  • Malwarebazaar — sample repository
💥 Impact Assessment & Attack Vectors
Understanding how ransomware gets in and what it destroys.

📧 Phishing / Spear Phishing

Malicious attachments (Office macros, ISO, LNK files) or links to credential harvesting pages. Business Email Compromise as initial vector. Most common entry point.

#1 Vector

🖥️ Exposed RDP

RDP on port 3389 exposed to internet. Brute-forced or purchased credentials from Initial Access Brokers (IABs) on dark web. Extremely common SMB/healthcare target.

#2 Vector

🔓 Unpatched VPN/Firewall

Exploiting Fortinet, Pulse Secure, Citrix, Palo Alto vulnerabilities. Often zero-day or n-day. Provides direct corporate network access. LockBit favorite.

#3 Vector

🔗 Supply Chain / MSP

Compromising Managed Service Providers (MSPs) or software vendors to push malware to all downstream clients simultaneously. Kaseya/REvil hit 1,500+ orgs at once.

High Impact

💾 Removable Media

USB drives with autorun, though rare in modern targeted attacks. More common in air-gapped OT/ICS environments (power, water, manufacturing).

OT/ICS Risk

🕳️ Drive-by Downloads

Malvertising or watering hole attacks serving malware via browser exploits. User visits legitimate-looking site; malware installs silently via browser vulnerabilities.

Opportunistic
💣 Impact Categories
🗄️ Data Loss & Unavailability▼
Files, databases, email stores encrypted. EHR systems offline. Production databases inaccessible. Recovery from backup (if intact) takes days–weeks. Without backups, data may be permanently lost. Financial impact: operational downtime + recovery costs + regulatory fines.
🏥 Critical Infrastructure Disruption▼
Hospitals divert patients, cancel surgeries. Colonial Pipeline attack (2021) halted fuel distribution on US East Coast for 6 days. Water treatment facilities, power grids — OT/ICS ransomware can be life-threatening.
📰 Reputational & Legal Damage▼
Data published on leak sites if ransom unpaid. GDPR/HIPAA breach notification requirements triggered. Class action lawsuits. Stock price drops. Customer trust erosion. Long-term brand damage. Regulatory investigations.
💀 Backup Destruction (Inhibit Recovery)▼
Attackers specifically target and destroy backup systems: VSS (Volume Shadow Copies), Veeam, Backup Exec, network shares. Also target NAS devices and cloud-synced backups. If no offline/immutable backup exists, recovery is impossible without paying. This is the most catastrophic impact because it removes all options.
🚨 SOC Response Framework
High-level incident response phases — your SOP will be built from these.
🔴 First 15 Minutes Are CriticalSpeed of containment directly determines blast radius. Every minute of delay = more encrypted files and more lateral movement. Prioritize: DETECT → SCOPE → CONTAIN (in that order, but fast).
1️⃣ Detection & Triage (L1)
L1 Task▼
Trigger Sources: SIEM alert, EDR alert, user report, helpdesk ticket, threat intel feed.

L1 Actions:
  • Verify the alert is genuine (not FP) — check EDR telemetry, event logs
  • Determine affected hostname(s), user account(s), IP addresses
  • Identify the ransomware family if possible (extension, note, VirusTotal)
  • Check if encryption is active or completed
  • Document everything with timestamps
  • Escalate to L2 immediately with initial findings
  • Do NOT power off the machine yet — volatile memory may contain keys
2️⃣ Scoping & Investigation (L2)
L2 Task▼
L2 Actions:
  • Determine patient zero — which host was first infected?
  • Identify initial access vector (phishing email? RDP? VPN?)
  • Map lateral movement — what other systems are affected?
  • Check for active C2 connections — block at firewall
  • Identify attacker persistence mechanisms
  • Determine if data exfiltration occurred
  • Check backup integrity — are backups safe?
  • Preserve forensic evidence (memory dump, disk image, logs)
3️⃣ Containment
Both Levels▼
Short-Term Containment:
  • Isolate affected hosts from network (VLAN, firewall rule, EDR isolation)
  • Disable compromised user accounts in AD
  • Block malicious IPs/domains at perimeter firewall and proxy
  • Disable VPN access if initial vector
  • Take backup snapshots of unaffected systems immediately
Long-Term Containment:
  • Deploy enhanced monitoring on adjacent systems
  • Force password resets across all privileged accounts
  • Patch the exploited vulnerability before recovery
4️⃣ Eradication
L2 Task▼
  • Remove all malware artifacts from affected systems
  • Delete attacker-created accounts, scheduled tasks, registry keys
  • Remove C2 implants (Cobalt Strike beacons, RATs)
  • Revoke and reissue compromised credentials and certificates
  • Rebuild compromised systems from clean images where possible
  • Validate complete removal before reconnecting to network
5️⃣ Recovery
Coordinated▼
  • Restore from clean, verified backups (offline/immutable preferred)
  • Prioritize critical business systems first
  • Test restored systems before production reconnection
  • Monitor closely for reinfection for 30+ days
  • Decryption only if law enforcement has decryptor (check No More Ransom)
  • Do NOT pay ransom without legal/exec approval — and even then, recovery not guaranteed
6️⃣ Lessons Learned & Reporting
Post-Incident▼
  • Full incident timeline reconstruction
  • Root cause analysis — how did attacker get in and persist?
  • Regulatory notifications (GDPR 72hr, HIPAA, SEC) if required
  • Law enforcement notification (FBI, CISA)
  • Insurance claim documentation
  • Security control gap analysis and remediation plan
  • Tabletop exercise updates based on gaps identified
🛠️ SOC Tools & Key Commands
Practical commands and tools you'll use during a ransomware incident.

🔎 Investigation Commands (Windows)

  • netstat -ano — Active connections + PIDs
  • tasklist /svc — Running processes + services
  • net user /domain — AD user enumeration
  • wevtutil qe Security /c:100 — Last 100 security events
  • Get-WinEvent -LogName Security | Where {$_.Id -eq 4625} — Failed logons
  • dir /s /b *.locked 2>nul — Find encrypted files
  • vssadmin list shadows — Check shadow copies
  • schtasks /query /fo LIST /v — All scheduled tasks
  • reg query HKLM\...\Run — Startup persistence
  • ipconfig /displaydns — DNS cache (C2 domains)

🛡️ Containment Commands

  • Disable-ADAccount -Identity [user] — Disable compromised account
  • netsh advfirewall set allprofiles state on — Enable firewall
  • netsh advfirewall firewall add rule name="Block C2" dir=out action=block remoteip=[IP] — Block C2 IP
  • net stop [servicename] — Stop malicious service
  • EDR: Isolate host from console (CrowdStrike / SentinelOne / Defender)
  • SIEM: Create suppression-free alert for affected subnet
  • Firewall: Block egress to Tor exit nodes (known IP lists)

🧰 Essential SOC Toolset for Ransomware

  • EDR: CrowdStrike, SentinelOne, Microsoft Defender for Endpoint
  • SIEM: Splunk, Microsoft Sentinel, Elastic SIEM
  • Memory Forensics: Volatility3, Redline
  • Disk Forensics: Autopsy, FTK Imager, Eric Zimmerman Tools
  • Network: Wireshark, Zeek, NetworkMiner
  • Malware Analysis: Any.run, Cuckoo Sandbox, VirusTotal
  • Ransomware ID: ID Ransomware (id-ransomware.malwarehunterteam.com)
  • Decryptors: NoMoreRansom.org
  • Threat Intel: MITRE ATT&CK Navigator
  • Log Analysis: Chainsaw, Hayabusa (EVTX fast analysis)
✅ Forensic Collection Priority Order1. Live memory (RAM) → 2. Running process list & network connections → 3. Windows Event Logs → 4. Prefetch files → 5. Registry hives → 6. Disk image. Collect in this order — most volatile first.
